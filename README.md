# Challenger — Sistema de Diárias e Passagens (CEAD/UFPI)

Gestão de solicitações de diárias e passagens, com fluxo de aprovação
(Solicitante → Direção → Financeiro → FADEX) e prestação de contas por relatório de viagem.

| Pasta | Conteúdo |
|---|---|
| `back/` | API REST — Node.js, Express 5, Prisma, PostgreSQL |
| `front/` | SPA — React 18, Vite, Tailwind, Zustand |
| `docs/INSTALACAO.md` | **Roteiro de instalação** (banco de dados e aplicação) |
| `docker-compose.yml` | PostgreSQL para desenvolvimento |

Veja [docs/INSTALACAO.md](docs/INSTALACAO.md) para instalar.
